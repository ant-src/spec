# Ant

Specification for Ant, a typed language with errors as values, pipes for data, and goroutines.

- [ant-lang.md](ant-lang.md) — the language specification
- [stdlib.md](stdlib.md) — the I/O standard library
- [fmt.md](fmt.md) — `ant fmt`, the source formatter
- [doc.md](doc.md) — `ant doc` and doc comments
- [lsp.md](lsp.md) — `ant lsp`, the language server
- [dap.md](dap.md) — `ant dap`, the debugger
- [test.md](test.md) — `ant test`, the test runner
